## 1. 모델 A 정의
KKBox 데이터로 학습한 재청취 확률 예측 모델입니다. 다양성 보정(B1·B2)은 적용하지 않은 기본 개인화 모델입니다.
- 구성: AdaBoost, LightGBM_v2, CatBoost_v2 의 확률(logit)을 로지스틱 회귀로 결합(스태킹)
- 스태킹 계수: {'AdaBoost': -0.2154, 'LightGBM_v2': 0.7299, 'CatBoost_v2': 0.4134}, 절편 0.0163
- 선정 규칙: 최고 AUC와 0.0005 이내, ECE 0.01 이하 중 모델 수 최소
- 학습 데이터: train_a + train_b에서 무작위 50만 행(AdaBoost는 그중 20만 행), 조기 종료는 valid 사용자 절반
- 입력 특성 45개(`_g0` 계열 포함, `_g30`·`source_*`·키 열 제외)

## 2. 데이터 분할
`row_order / 7,377,418` 비율 기준 블록 분할: 준비 기간(0~0.2, 기록 전용), train_a(0.2~0.4), train_b(0.4~0.6), valid(0.6~0.8), test(0.8~1.0). 모든 특성은 블록 시작 시점 이전 기록으로만 계산하고 `_g0`(지연 없음)·`_g30`(30일 확정분) 두 버전을 만들었습니다.

## 3. 사전 합격선
모델 AUC > 인기도 AUC 이고, 사용자 단위 부트스트랩 AUC 차이의 95% 신뢰구간 하한 > 0

## 6. 한계와 미해결 항목
- `_g30`(현실 조건) 평가에서 AUC가 크게 낮아지고 확률이 과대예측됩니다. 서비스 적용 시 `_g30` 조건 학습 또는 확률 보정이 필요합니다.
- `membership_days`는 만료일을 사용해 미래 정보일 수 있습니다. 팀 확인이 필요합니다.
- 후보곡이 실제로 들은 곡뿐이라 선택 편향이 있습니다. 상위 10곡 재청취율은 절대값이 아니라 순위 정렬 확인용입니다.
- `valid`를 여러 번 보고 설계를 정했으므로 valid 점수는 낙관적일 수 있고, test는 1회만 평가했습니다. 이후 모델·특성 변경은 사후 조정입니다.
- `pred_valid_modelA_final.parquet`의 tune 절반은 메타 모델 학습 구간(in-sample)이라 `is_tune` 열로 구분해 사용합니다.
- 시간에 따른 target 평균 하락(0.548 → 0.405)으로 test AUC가 valid보다 낮습니다.
- Kaggle 데이터 이용 조건과 나이·성별 사용 가능 여부는 외부 공개 전 확인이 필요합니다.
